# رویش ۳.۹ — ساخت APK با ML Kit آفلاین

این مخزن خصوصی، بستهٔ سورس پروژهٔ رویش ۳.۹ را به همراه گردش‌کار ساخت ابری نگه می‌دارد. در ساخت ابری، سورس استخراج می‌شود، بررسی‌های ایستا اجرا می‌شوند و APK آزمایشی اندروید ساخته می‌شود.

## ساخت APK
1. تب **Actions** را باز کن.
2. گردش‌کار **Build Rooyesh 3.9 ML Kit APK** را انتخاب کن.
3. روی **Run workflow** بزن.
4. وقتی اجرا تمام شد، از بخش **Artifacts** فایل rooyesh-3.9-mlkit-debug را دانلود کن.

این APK آزمایشی با شناسهٔ جداگانه ساخته می‌شود و کنار نسخهٔ قبلی نصب می‌شود؛ جایگزین نسخهٔ اصلی نیست. ترجمهٔ آفلاین انگلیسی↔فارسی به مدل ML Kit نیاز دارد که بار اول باید با اینترنت دانلود شود.

فایل rooyesh-source.tar.gz شامل سورس برنامه است. کلید خصوصی یا فایل keystore در این مخزن قرار نمی‌گیرد.
