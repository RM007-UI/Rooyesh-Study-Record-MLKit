# رویش ۳.۹ — ML Kit آفلاین

این مخزن سورس برنامه و گردش‌کار ساخت APK را نگه می‌دارد.

## دانلود APK
از بخش [Releases](https://github.com/RM007-UI/Rooyesh-Study-Record-MLKit/releases) فایل `Rooyesh_3.9_MLKit_Debug.apk` را از قسمت **Assets** دانلود کن.

## سورس برنامه
- پوشهٔ `source/`: فایل‌های پروژه به‌صورت بازشده و قابل بررسی
- فایل `rooyesh-source.tar.gz`: آرشیو فشردهٔ سورس مورد استفاده در ساخت
- مسیر `.github/workflows/build-apk.yml`: گردش‌کار بررسی و ساخت برنامه

هر بار که سورس آرشیوشده یا گردش‌کار ساخت تغییر کند، GitHub Actions برنامه را می‌سازد، سورس‌های بازشده را به مخزن اضافه می‌کند و APK را در یک Release آزمایشی منتشر می‌کند.

## نکات نصب
این APK نسخهٔ آزمایشی **debug** است. شناسهٔ نصب آن ممکن است با نسخه‌های قبلی فرق داشته باشد. ترجمهٔ آفلاین انگلیسی↔فارسی برای بار اول به اینترنت نیاز دارد تا مدل ML Kit دانلود شود؛ بعد از آن می‌تواند آفلاین کار کند.
