# رویش ۳.۱۰.۱ — سورس کامل با ML Kit واقعی و پشتیبان کامل

این پروژه نسخهٔ فعلی رابط رویش (یادداشت‌ها، برنامه‌ریز، PDF، تقویم شمسی/میلادی، درخت رشد، تنظیمات و پشتیبان کامل) را با میزبان بومی Android WebView و موتور ترجمهٔ آفلاین Google ML Kit ترکیب می‌کند.

**این ZIP خودش APK نیست.** در محیط محلی Android SDK و دسترسی شبکه به Google Maven در دسترس نیست. گردش‌کار GitHub Actions پوشهٔ source/ را مرجع قطعی کد می‌گیرد، آزمون‌های ایستا را اجرا می‌کند و با Android SDK کد را کامپایل می‌کند.

## قابلیت‌های مترجم ML Kit

- انگلیسی ↔ فارسی از طریق API رسمی `com.google.mlkit:translate:17.0.3`
- دکمهٔ دانلود مدل روی خود صفحه، با تأیید کاربر پیش از مصرف اینترنت
- بررسی وجود مدل قبل از ترجمه؛ ترجمهٔ آفلاین به واژه‌نامهٔ محدود سقوط نمی‌کند و اگر مدل نباشد، پیام دانلود نشان می‌دهد
- پس از دانلود مدل، ترجمه روی خود گوشی انجام می‌شود
- حالت آنلاین MyMemory جدا نگه داشته شده و متن آن به سرویس خارجی ارسال می‌شود
- رابط بر اساس آخرین سورس پشتیبان کامل ۳.۸ ادغام شده تا قابلیت‌های جدیدتر از دست نروند

## ساخت ابری از GitHub Actions

Workflow در `.github/workflows/build-apk.yml` با اجرای دستی (`workflow_dispatch`) ساخته شده است. بعد از قرار دادن پوشهٔ پروژه در یک مخزن خصوصی GitHub، از تب **Actions** workflow با نام **Build and release Rooyesh 3.10.1** را اجرا کن.

### APK اصلی و نسخهٔ آزمایشی

- وقتی چهار Secret امضای قبلی (ROOYESH_KEYSTORE_B64، ROOYESH_STORE_PASSWORD، ROOYESH_KEY_ALIAS و ROOYESH_KEY_PASSWORD) تنظیم باشند، workflow نسخهٔ Release با شناسهٔ com.rooyesh.study.app و نسخهٔ 3.10.1 را می‌سازد؛ امضا با همان کلید قدیمی اجازه می‌دهد برنامه روی نسخهٔ اصلی قبلی به‌روزرسانی شود.
- اگر کلید امضا حاضر نباشد، workflow فقط نسخهٔ Debug با شناسهٔ جداگانهٔ com.rooyesh.study.app.mlkitdebug می‌سازد و صریحاً آن را به‌عنوان آزمایشی منتشر می‌کند. APK آزمایشی جای نسخهٔ اصلی نصب‌شده را نمی‌گیرد.
- کلید خصوصی یا فایل keystore.properties را در مخزن یا آرشیو سورس قرار نده. فقط از GitHub Actions Secrets استفاده کن.

## اجرای محلی با Android Studio

- JDK 17
- Android SDK Platform 35 و Build Tools 35.0.0
- Android Gradle Plugin 8.8.2 و Gradle 8.10.2
- دسترسی شبکه برای دانلود `com.google.mlkit:translate:17.0.3` از Google Maven

برای نسخهٔ قابل‌به‌روزرسانی، فایل `keystore.properties` را در ریشهٔ پروژه بساز و کلید موجود را فقط در مسیر امن نگه دار. فایل کلید و `keystore.properties` عمداً در ZIP نیستند و در `.gitignore` آمده‌اند.

## بررسی‌ها

Workflow نحو JavaScript را با Node بررسی می‌کند و همچنین بررسی ایستا می‌کند که dependency واقعی ML Kit، پل بومی ترجمه، دکمهٔ دانلود مدل، مجوز اینترنت، شناسهٔ بسته و قابلیت پشتیبان کامل در پروژه باقی باشند. این بررسی‌ها جایگزین آزمایش واقعی APK نیستند؛ بعد از build باید مدل دانلود و هر دو جهت ترجمه روی گوشی امتحان شوند.

## قابلیت‌های تازهٔ ۳.۱۰.۱
- درخواست مجوز اعلان در شروع برنامه و اعلان پیوستهٔ تقویم مطالعه با آیکون سفید اختصاصی.
- یادآوری روزانه در ساعت ۱۳ اگر تا آن زمان مطالعه‌ای ثبت نشده باشد؛ زمان‌بندی پس از راه‌اندازی دوبارهٔ گوشی نیز بازیابی می‌شود.
- ثبت حال‌وهوای روز پس از کامل‌شدن هدف، نمایش آن در تقویم و جمع‌بندی هفتگی/ماهانه.
- پیام‌های متناسب با هر حالت که تا تمام‌شدن مجموعه تکرار نمی‌شوند.
- جعبه ابزار با ترجمه، مرور نکته‌های قواعد عربی و جدول تناوبی قابل جست‌وجوی ۱۱۸ عنصر.
